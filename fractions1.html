Fractions

📘 Explication

Une fraction représente une partie d'un tout.


Dans une fraction a / b, a est le numérateur et b est le dénominateur.


Le dénominateur ne peut jamais être égal à zéro.

📌 Règle essentielle

Pour additionner ou soustraire deux fractions, elles doivent avoir le même dénominateur.

Exemple :

2/5 + 1/5 = 3/5


Pour multiplier deux fractions, on multiplie les numérateurs entre eux et les dénominateurs entre eux.

✏️ Exemple

Calculons :


1/4 + 2/4


Les dénominateurs sont identiques.

On additionne donc les numérateurs :

1 + 2 = 3


Résultat : 3/4

🧠 Exercice

Calcule :


A = 2/7 + 3/7

B = 4/9 × 2/3


Voir la correction

A = 5/7

B = 8/27

⭐ À retenir

  • Le numérateur est au-dessus de la barre.
  • Le dénominateur est en dessous.
  • Pour additionner des fractions, on utilise un même dénominateur.
  • Pour multiplier des fractions, on multiplie les numérateurs et les dénominateurs.
  • Le dénominateur ne doit jamais être nul.
