📘 Explication

Une équation est une égalité qui contient un nombre inconnu, souvent représenté par x.


Résoudre une équation consiste à trouver la valeur de x qui rend l'égalité vraie.

📌 Règle essentielle

On peut ajouter, soustraire, multiplier ou diviser les deux membres d'une équation par un même nombre non nul, sans changer l'égalité.

✏️ Exemple 1

Résolvons :


x + 5 = 12


On soustrait 5 aux deux membres :

x = 12 − 5

x = 7

✏️ Exemple 2

Résolvons :


3x = 15


On divise les deux membres par 3 :

x = 15 ÷ 3

x = 5

🧠 Exercice

Résous les équations suivantes :


A : x + 8 = 20

B : x − 6 = 10

C : 4x = 28


Voir la correction

A : x = 12

B : x = 16

C : x = 7

⭐ À retenir

  • Une équation contient une égalité et une inconnue.
  • Résoudre une équation signifie trouver la valeur de x.
  • Toute opération effectuée sur un membre doit être effectuée sur l'autre membre.
  • Toujours vérifier la solution dans l'équation de départ.
