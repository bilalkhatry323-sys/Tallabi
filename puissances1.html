📘 Explication

Une puissance permet d'écrire plus simplement une multiplication répétée du même nombre.


Par exemple :

2 × 2 × 2 × 2 = 2⁴


Dans 2⁴, 2 est la base et 4 est l'exposant.

📌 Règle essentielle

aⁿ signifie que l'on multiplie a par lui-même n fois.

Exemple :

5³ = 5 × 5 × 5 = 125


Pour une base non nulle :

a¹ = a

a² = a × a

a⁰ = 1

✏️ Exemple

Calculons :


3⁴


3⁴ = 3 × 3 × 3 × 3

3 × 3 = 9

9 × 3 = 27

27 × 3 = 81


Donc : 3⁴ = 81

🧠 Exercice

Calcule :


A = 2⁵

B = 4²

C = 10³


Voir la correction

A = 32

B = 16

C = 1000

⭐ À retenir

  • Une puissance est une multiplication répétée.
  • Dans aⁿ, a est la base et n est l'exposant.
  • a² signifie a × a.
  • Pour toute base non nulle, a⁰ = 1.
